# Lumi
Lumi is a light controlling software to create your light displays, simulate your light virtually on your screen, and then play the show live.
It supports serial port communication.

> [!NOTE]
> Lumi is a quick and dirty project I made a while ago to test things up with my light show, and it is now deprecated.
> If you are searching for a similar project, I highly recommend you check out [Xlights](https://xlights.org), as this is exactly what I wanted to recreate with Lumi


## Installation
Clone this repo and do `pip3 install python-tk pyserial`
Start lumi.py
